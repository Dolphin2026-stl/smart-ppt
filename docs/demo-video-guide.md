# Demo video guide

Use OBS to record a self-authored template, then edit with your preferred editor. Suggested flow: introduce the skill, put a complete PPTX folder under templates/, index and select a template, edit one page while keeping the rest, then validate and open the result.

Do not show private templates, logos or personal paths in public recordings. The bundled GIF reconstructs real command outputs and actual PowerPoint renders; it is not a live screen recording. No hosted demo video is currently published.
